# Bugfix Summary - Toolbar Crash Issues
**Date**: 2025-11-23
**Issue**: Toolbar crashes when activating the Advanced Grid Tool

---

## Root Causes Identified

### 1. **Missing Query Safety Checks**
- `RenderGridOverlay()` was calling `GetSingleton()` on empty queries
- No validation before accessing `GuideLineSettingsData`
- Could crash if rendering settings aren't loaded yet

### 2. **Invalid Grid Generation**
- `GenerateStandardGrid()` didn't check if start/end positions were identical
- Would attempt to normalize zero-length vector → NaN values → crash
- No terrain system validation before sampling height

### 3. **Null Reference in UI Bindings**
- Bindings accessed `_gridToolSystem` without null checks
- Would crash if system wasn't initialized yet
- `Keyboard.current` could be null in some scenarios

### 4. **Unhandled Exceptions in UI System**
- No try-catch in `OnCreate()` method
- Errors during initialization would crash entire UI
- No graceful error handling

### AdvancedGridToolUISystem.cs

#### Fix 3: UI System Error Handling
```csharp
protected override void OnCreate()
{
    base.OnCreate();
    Instance = this;
    _log = LogManager.GetLogger(...);

    try
    {
        // Get system references
        _gridToolSystem = World.GetOrCreateSystemManaged<AdvancedGridToolSystem>();
        _toolSystem = World.GetOrCreateSystemManaged<ToolSystem>();

        // ADDED: Null check after getting systems
        if (_gridToolSystem == null || _toolSystem == null)
        {
            _log.Error("Failed to get required system references");
            return;
        }

        // Rest of initialization...
    }
    catch (Exception ex)
    {
        _log.Error($"Error creating UI System: {ex.Message}");
        _log.Error($"Stack trace: {ex.StackTrace}");
    }
}
```

#### Fix 4: Binding Null Safety
```csharp
private void CreateBindings()
{
    // ADDED: Safety check before creating bindings
    if (_gridToolSystem == null || _toolSystem == null)
    {
        _log.Error("Cannot create bindings: system references are null");
        return;
    }

    // All bindings now include null checks
    AddUpdateBinding(new GetterValueBinding<bool>(
        "AdvancedGridTool",
        "IsActive",
        () => _toolSystem != null && _gridToolSystem != null &&
              _toolSystem.activeTool == _gridToolSystem
    ));

    AddUpdateBinding(new GetterValueBinding<float>(
        "AdvancedGridTool",
        "Spacing",
        () => _gridToolSystem != null ? _gridToolSystem.Spacing : 50f
    ));

    // ... all other bindings have similar null checks
}
```
